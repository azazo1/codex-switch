# Codex Switch v0.14.0

Date: 2026-09-09

本版本新增应用内自动更新, 检查, 下载, 校验和安装都可以在应用内完成, 不再需要手动去 GitHub 下载; 同时修复了上游余额为负或为零时被误判为查询失败的问题. 使用旧配置的用户请先阅读 Upgrade Notes 再升级.

## Highlights

- 新增应用内自动更新: 启动时静默检查新版本, 托盘和仪表盘都能手动检查, 更新弹窗内完成下载, 校验和安装.
- Linux 与 Windows 更新后自动替换程序文件, 重启即生效; macOS 自动打开安装镜像引导拖拽安装.
- 下载的更新包使用发布校验和文件 SHA256SUMS 验证完整性.
- 修复上游余额为负或为零时被误判为查询失败的问题.

## Upgrade Notes

1. 升级不涉及数据库迁移, 现有上游, 日志和设置保持不变.
2. 默认在启动 5 秒后静默检查一次更新, 发现新版本会发系统通知; 不希望自动检查时, 在托盘菜单或更新弹窗里关闭 "启动时自动检查更新".
3. Windows 通过应用内更新后, 旧程序文件会以 `.old` 后缀留在原目录, 下次启动时自动清理; 安装目录只读导致更新失败时, 更新弹窗会提示并给出 Release 页链接.
4. 升级后可以在仪表盘的 "当前版本" 一行点击 "检查更新" 验证新流程, 当前已是最新版本时会提示 "已是最新版本".

## Features

- 自动更新: 支持 Linux, Windows 和 macOS 的 x86_64 与 aarch64 六个目标, 按当前平台自动匹配发布资产.
- 自动更新: 更新弹窗展示 release notes 和下载进度, 支持跳过指定版本, 重新检查和跳转 Release 页; Linux 与 Windows 下载完成后提供一键重启.
- 自动更新: 下载使用流式写入并走系统代理, 无法直连 GitHub 的环境也能正常更新.
- 自动更新: 状态栏和仪表盘显示当前版本与检查入口, 托盘菜单提供手动检查和自动检查开关.
- 诊断: panic 信息现在会写入主日志, 包含出错位置和消息, Windows 上闪退不再无迹可寻.

## Bug Fixes

- 余额: 修复 DeepSeek, OpenRouter, Novita 以及常见中转面板上游余额为负或为零时被误判为查询失败的问题, 现在正常显示金额和单位, 补充说明保留在悬浮提示中.
- 余额: DeepSeek 返回 `is_available=false` 时转为余额快照上的提示消息, 不再使快照失效.
