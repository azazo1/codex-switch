# Codex Switch v0.15.0

Date: 2026-09-09

本版本补齐桌面应用的单实例, 启动设置和更新下载体验. 同一数据目录只允许一个实例运行, 二次打开会唤起已有窗口; 代理服务和节点监听都可以选择启动时自动启用; 更新下载支持取消和断点续传. 使用旧配置的用户请先阅读 Upgrade Notes 再升级.

## Highlights

- 同一数据目录只允许一个实例, 再次启动会把已有窗口显示到前台, 调试实例和正式实例仍可并行.
- 仪表盘和节点页新增启动设置: 启动时隐藏主窗口, 启动时启用服务, 启动时启用节点监听.
- 更新下载可以取消, 并支持从 `.part` 文件断点续传; 手动检查更新后, 启动时的静默检查不会再抢状态.
- 系统代理变化后, 后续出站请求会使用新的代理设置, 不再沿用启动时的旧连接.

## Upgrade Notes

1. 升级不涉及数据库迁移, 现有上游, 日志和设置保持不变. 新增的启动设置默认关闭, 行为与升级前一致.
2. 正式实例和 `just debug` 使用不同数据目录, 因此可以同时运行; 同一数据目录下的第二次启动会退出并唤起已有窗口, 不再各自监听同一端口.
3. 需要开机后自动转发时, 在仪表盘勾选 "启动时启用服务", 需要节点转发时再在节点页勾选 "启动时启用节点监听". 只想后台驻留时勾选 "启动时隐藏主窗口".
4. 更新下载中途取消会保留 `.part` 文件, 下次点 "立即更新" 会从断点继续; 校验失败会删除 `.part` 并提示重试.
5. 升级后可以在仪表盘确认版本号, 并按需勾选启动设置; 二次打开应用应只看到一个主窗口.

## Features

- 单实例: 锁与数据目录绑定, unix 使用数据目录内 socket, Windows 使用按路径哈希的 named pipe. 二次启动转发启动参数后退出, 已有实例显示并聚焦主窗口.
- 启动设置: 仪表盘提供 "启动时隐藏主窗口" 和 "启动时启用服务", 节点页提供 "启动时启用节点监听", 勾选后立即保存, 下次启动生效.
- macOS: 新增 "隐藏窗口时隐藏 Dock 图标" 开关, 默认开启; 关闭后窗口隐藏到托盘时 Dock 图标保持显示.
- 托盘: 右键菜单首部以禁用项显示应用名和当前版本.
- 退出: 从终端启动时, Ctrl+C 走统一退出路径, 会停止代理和节点监听, 释放单实例锁后再退出.
- 自动更新: 下载中可取消, 取消后回到可再次下载的状态, `.part` 保留供续传.
- 自动更新: 已有 `.part` 时携带 Range 请求续传, 服务器不支持续传时从头下载, 下载完成后整文件校验 SHA256.
- 自动更新: Linux 与 Windows 点击 "重启应用" 前会先释放单实例锁, 避免新进程抢锁失败.

## Bug Fixes

- 自动更新: 修复 "查看 Release 页" 在部分环境下点击无反应的问题, 现在通过系统命令打开浏览器, 成功或失败会显示在状态栏.
- 自动更新: 修复启动后 5 秒的静默检查与手动检查抢状态的问题, 手动检查后自动检查会让位.
- HTTP: 修复系统代理变更后应用仍使用启动时旧代理的问题, 后续出站请求会重建 client.
- HTTP: User-Agent 改为使用构建版本号, 不再固定写成 `codex-switch/0.1.0`.
