# Codex Switch v0.16.2

Date: 2026-09-11

本版本把余额自动刷新拆成活跃与空闲两档间隔, 仪表盘费用合计改为对已写入日志求和, 并让测试台的临时上游也能拉取模型列表.

## Highlights

- 余额自动刷新新增活跃间隔与活跃窗口, 上游有模型调用时按更短的间隔查询, 空闲后自动回落到长间隔.
- 仪表盘的总估算, 今日估算和按上游估算改为对日志中已写入的费用求和, 修改计价脚本或刷新模型价格不再改写历史合计.
- 测试台的临时上游可以直接拉取模型列表, 并从列表中选择模型名.

## Upgrade Notes

1. 升级会自动执行数据库迁移 26, 给余额刷新配置补上活跃间隔和活跃窗口两列, 已有上游, 日志和设置保持不变.
2. 余额刷新后台扫描周期由 `30` 秒缩短到 `5` 秒, 两个间隔也不再限制最小 `60` 秒. 想完全保持原来的稀疏刷新, 可以把活跃间隔填成与空闲间隔相同.
3. 仪表盘合计的口径变化后数值可能与升级前不同, 现在与日志页中同一批日志的费用一致.

## Features

- 余额提醒: 新增 `活跃间隔秒` (默认 `5`) 和 `活跃窗口秒` (默认 `10`). 上游有在途模型调用, 或最后一次调用结束后仍在活跃窗口内, 按活跃间隔查询; 否则按空闲间隔查询 (原 `检查间隔秒`). 缓存保活请求同样计入活跃.
- 余额提醒: 后台扫描周期由 `30` 秒缩短到 `5` 秒, 间隔可设到 `1` 秒.
- 上游列表: 自动刷新列显示 `活跃 Xs / 空闲 Xs`, 悬停可以看到两个间隔的含义.
- 模型测试台: 临时上游按 Base URL 拉取模型列表, 使用页面上填写的 API Key, 拉取按钮与直连上游位置一致; 切换上游或修改 Base URL 后不会沿用上一次的列表.

## Bug Fixes

- 仪表盘: 总估算, 今日估算和按上游估算改为对已写入日志的费用求和, 与单条日志使用同一份快照. 此前汇总会按当前价格缓存和当前脚本链路重新估算, 与日志数值不一致.
