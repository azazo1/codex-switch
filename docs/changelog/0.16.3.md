# Codex Switch v0.16.3

Date: 2026-09-20

本版本为上游新增并发限制, 可以选择并发打满时直接拒绝请求或排队等待空位.

## Highlights

- 上游支持设置并发上限, 约束同时转发到该上游的请求数.
- 并发打满时可以在编辑页选择 `满时拒绝` 或 `满时排队` 两种处理方式.

## Upgrade Notes

1. 升级会自动执行数据库迁移 27, 给上游表补上并发限制和满载策略两列, 已有上游的默认行为不变 (`0` 表示不限制).
2. 并发限制默认关闭, 需要限制某个上游时在其编辑页把 `并发限制` 调到大于 `0`.

## Features

- 上游编辑页: 新增 `并发限制` 输入框, `0` 表示不限制. 计数从向上游发起请求开始, 到响应完全结束 (含流式输出) 为止, 对 Relay API Key, Codex OAuth 和 peer 节点上游都生效.
- 上游编辑页: 并发上限大于 `0` 时出现满载策略选项. `满时拒绝` 直接向客户端返回 `429` 错误, 不计入调度失败, 也不会切换到同组其他上游; `满时排队` 挂起请求等待空位, 等待期间可以在活跃连接页终止.
- 修改并发上限后立即对新请求生效; 上限调小时已在途的请求会自然结束后释放, 存在短暂的过渡窗口.
- 模型测试台直连上游的请求不经过该限制.
