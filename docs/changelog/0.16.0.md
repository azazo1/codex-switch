# Codex Switch v0.16.0

Date: 2026-09-10

本版本新增可保存的计价脚本. 仪表盘可以编辑全局脚本, 上游编辑器可以给单个上游单独写脚本, 估算按上游脚本, 全局脚本, 内置公式的顺序取第一份有效结果. 同时补齐 macOS 窗口快捷键和原生全屏, 并收紧日志表格与访问 key 的展示. 使用旧配置的用户请先阅读 Upgrade Notes 再升级.

## Highlights

- 可用 Rhai 脚本覆盖费用估算: 全局一份, 每个上游还可以单独一份, 保存后立即生效.
- 脚本编辑器提供预设模板和应用内文档, DeepSeek 官方价会在 Base URL 匹配的上游上预选.
- 脚本可以用 `charge()` 按余额单位扣减展示余额, 本地调整用警告色标出, 下次成功刷新会整份覆盖.
- macOS 支持 `Cmd+W`, `Cmd+M`, `Ctrl+Cmd+F` 和 `Fn+F` 原生全屏; 启动时不再把刚显示的窗口拖进新的全屏 space.
- 仪表盘和临时 key 列表只显示头尾 8 位, 复制和编辑仍使用完整 key.

## Upgrade Notes

1. 升级会写入计价脚本设置, 并新增 `upstream_pricing_scripts` 表以及余额快照的 `remaining_adjusted` 字段. 现有数据库会自动迁移, 没有降级 migration.
2. 全局和上游计价脚本默认关闭, 未启用时费用估算与 v0.15.1 相同.
3. 需要自定义计价时, 在仪表盘价格缓存一行打开 `计价脚本`, 或在上游编辑器里给该上游单独编写. 优先级是上游脚本 > 全局脚本 > 内置公式, 详见[费用估算与计价脚本](https://github.com/azazo1/codex-switch/blob/main/docs/pricing-guide.md).
4. `charge()` 只在请求落库时扣减展示余额, 并打上本地调整标记; 下次手动查询或自动刷新成功会整份覆盖. 本地扣减不触发余额提醒.
5. 使用较新版本打开数据库后, 不保证 v0.15.1 还能读取. 升级后可在仪表盘确认版本号, 并按需打开计价脚本做一次试算.

## Features

- 计价脚本: `fn estimate(ctx)` 在请求写入, 缓存保活, 模型测试和仪表盘汇总时执行, 返回 USD 或 `()` 以回退下一层.
- 计价脚本: 注入 usage, price, upstream (含 base_url), builtin, multiplier, fx, utc/local 时间和余额快照, 并提供 `usd_for_tokens` 与 `charge`.
- 计价脚本: 仪表盘和上游编辑器都能打开编辑窗口, 支持即时编译, 试算, 预设填入和应用内文档.
- 计价脚本: 上游脚本随上游导出和导入一起迁移.
- 余额: 脚本扣减后的 remaining 用警告色显示, 查询得到的余额仍用默认文字色.
- macOS: `Window` 菜单提供关闭, 最小化, 缩放和进入全屏.
- 界面: 测试台页签移到调度组之后, 日志页之前.

## Bug Fixes

- macOS: 修复启动时恢复全屏会把刚显示的窗口拖进新 space 的问题. 现在等窗口可见后再切换, 隐藏到托盘时暂停, 最多重试 5 次.
- 日志: 模型列按当前页最长标签收宽度, 短名字不再撑开整表; 空间不够时截断并保留尾部, 保证 token, 费用和耗时列可见.
- 计价脚本: 试算日志只保留最近一次试算, 请求估算不再灌进编辑器; 脚本框中的 Tab 插入两个空格.
- 界面: 等宽编辑器优先使用系统等宽字体, 避免中文 UI 字体把代码拉成比例宽.
