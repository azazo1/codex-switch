# Codex Switch v0.16.5

Date: 2026-09-27

本版本给套餐型上游补上额度窗口展示, 并让 DeepSeek 官方这类 Responses 上游能把思维链随请求传回去.

## Highlights

- Command Code 和智谱 GLM Coding Plan 可以在托盘, 上游列表和仪表盘看到 `5h` / `1w` / `1month` 剩余百分比; Codex OAuth 的 `5h` / `7d` 也用同一套展示.
- 上游编辑器新增 `显示额度窗口`: 勾选后只看窗口, 查不到时显示 `无额度窗口`; 取消勾选则只看金额余额.
- Responses 中转上游可开启 `还原 reasoning_text`, 避免 DeepSeek 官方在思考模式遇到外来工具调用时返回 `400`.

## Upgrade Notes

1. 升级会自动执行数据库迁移 `28`, `29`, `30`: 余额快照补 `windows` 列, 上游补 `show_quota_windows` (默认勾选) 和 `restore_reasoning_text` (默认关闭). 没有降级 migration.
2. 已有 Command Code, 智谱和 Codex OAuth 上游会默认显示额度窗口. 想继续看金额余额时, 在上游编辑器取消勾选 `显示额度窗口`.
3. 额度窗口没有金额, 不会触发余额提醒, 需要自己看托盘或上游列表里的剩余百分比.
4. `还原 reasoning_text` 默认关闭. 只有接到 DeepSeek 官方 `400 The reasoning_text in the thinking mode must be passed back to the API` 这类错误时才需要打开; 打开后这段文本会开始计入输入 token.
5. 升级后可在仪表盘确认版本号, 并在上游列表对照余额列是否变成窗口百分比.

## Features

- 套餐额度: Command Code 按 `windowLimits` 查询 `5h`, `1w` 和月度积分池; 智谱 GLM Coding Plan 查询 `5h` 和每周窗口. 按 Base URL 自动识别, 不需要改 `余额 provider`.
- 套餐额度: 窗口写入余额快照, 沿用现有的手动 `查余额` 和自动刷新. 智谱查不到窗口时回落到金额余额查询; Command Code 没有金额接口, 纯按量付费套餐显示月度积分.
- 界面: 勾选 `显示额度窗口` 时, 托盘标题用 `42/49/60`, 上游列表和仪表盘用 `42%/49%/60%`, 悬停显示逐窗口明细. 窗口隐藏到托盘时仍随后台刷新更新.
- 上游编辑器: `显示额度窗口` 放在 `余额 provider` 右侧. 识别不出套餐接口且不是 Codex OAuth 时置灰, 运行时忽略数据库里过期的勾选.
- 上游编辑器: Responses 中转上游新增 `还原 reasoning_text`. 开启后保留已有 `content`, 否则从代理自存编码和 `summary` 写回 `content[].reasoning_text` 并丢掉 `summary`; 整段历史没有 reasoning 项但有工具调用时补占位项. Codex OAuth 和节点上游始终走 `summary` 形态.

## Bug Fixes

- 智谱: 新套餐按积分计量返回 `CREDIT_LIMIT` 而不是 `TOKENS_LIMIT`, 旧过滤会丢掉 `5h` 和每周窗口, 勾选后一直停在 `无额度窗口`. 现在两种 type 都认, 缺少 `percentage` 时用 `currentValue` 和 `usage` 推算已用比例.
