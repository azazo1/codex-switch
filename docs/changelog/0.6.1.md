# Codex Switch v0.6.1

本版本聚焦上游调度和网络连接稳定性, 同时改进 Windows 发布产物和 Sub2Api 用量查询.

## Fixes

- 对启用重试的上游, 普通 HTTP 4xx 会进入阈值驱动的故障切换. 失效上游关联的会话亲和性会被清除, 后续请求可重新选择健康上游.
- Sub2Api 余额查询会优先请求根路径 `/v1/usage`, 以适配 Base URL 包含额外路径的配置.
- HTTPS 客户端同时信任 Mozilla WebPKI 根证书和本机系统根证书, 覆盖常见公开服务与企业本地 CA.
- Windows release executable 现在包含多分辨率应用图标.

## Upgrade Notes

- 本版本不包含数据库 schema migration, 不需要手动迁移数据.
