# Codex Switch v0.12.1

Date: 2026-08-28

本版本修复节点页在发现刷新时无法编辑监听地址的问题, 并让顶部刷新真正重新发现节点.

## Highlights

- 编辑 `监听节点请求` 地址时, 发现列表更新不会再把输入框盖回旧值.
- 点击 `刷新` 会清空已发现节点, 并按当前 mDNS / LND 开关重新发现.

## Bug Fixes

- 节点: 后台发现刷新只更新指纹, 待确认, 发现和已配对列表, 不再覆盖正在编辑的地址, 显示名和发现开关.
- 节点: 顶部刷新会重启发现; 节点监听未启动时只清空发现列表, 不会对外广播.

## Upgrade Notes

1. 从 0.12.0 升级无需额外数据库迁移.
2. 改完 `启用 mDNS` 或 `启用 LND` 后, 在节点监听已启动时点 `刷新` 即可重新发现, 不必先停止再启动监听.
3. 用一次编辑监听地址和一次刷新, 确认输入框不再跳动, 发现列表会重建.
