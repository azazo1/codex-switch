# Codex Switch v0.8.0

本版本为 Chat Completions 上游增加可选的 server tool 过滤, 方便接入 OpenCode Go 等只支持 function 工具的兼容端点.

## Chat Server Tools

- 上游新增 "过滤 server_tool" 开关, 仅在 Wire API 为 Chat Completions 时可用.
- 开启后会丢弃 web_search/web_search_preview 等非 function 工具, 并清理引用已删除工具的 tool_choice.
- 全部工具都被过滤时, 请求会移除 tools, tool_choice 和 parallel_tool_calls, 避免上游返回 400.

## OpenCode Go

- 文档补充 OpenCode Go 接入配置: Base URL 使用 https://opencode.ai/zen/go/v1, Wire API 选择 Chat Completions 并开启过滤.
- Codex 客户端仍通过 Codex Switch 本地 Base URL 接入, 不需要直接配置 OpenCode Go 为 Codex provider.

## Upgrade Notes

- 升级时会自动执行 schema migration 15, 不需要手动迁移数据.
- 该开关默认关闭, 现有 Chat 上游行为不变.
