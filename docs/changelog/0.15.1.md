# Codex Switch v0.15.1

Date: 2026-09-09

本版本修复 macOS 更新时无法替换已安装应用的问题. 此前点击 `立即更新` 只会打开安装镜像, 而应用进程仍占用 `Applications` 中的 `Codex Switch.app`, 系统会拒绝覆盖, 拖拽替换无法完成.

## Highlights

- macOS 更新改为自动替换: 应用退出后由替换脚本完成挂载, 替换和重新启动, 不再需要手动拖拽.
- 替换失败会回滚并把原因写回应用, 下次启动的更新窗口会显示具体原因.

## Bug Fixes

- 自动更新 (macOS): 修复挂载 DMG 后无法在 `Applications` 中替换应用的问题. 应用在下载校验完成后会写出替换脚本并立即退出, 由脚本等旧进程消失后挂载镜像, 复制新版本到目标同目录的临时路径, 再以改名让位的方式替换 bundle, 最后重新拉起应用.
- 自动更新 (macOS): 替换失败不再让应用凭空消失. 旧进程 60 秒未退出, 目标目录不可写, 镜像挂载失败, 镜像中没有 `.app` 或复制失败时, 脚本会保留原应用并把原因写入结果文件, 重新拉起应用后在更新窗口显示; 替换到一半失败会回滚到原版本.
- 应用界面: 修复单次测试结果卡片的排版, 回复内容与对话测试统一限制为可用宽度的 75%, 并去掉多余的 `回复` 标题.

## Upgrade Notes

1. 升级不涉及数据库迁移, 现有上游, 日志和设置保持不变.
2. 从 v0.15.0 及更早版本升级时, 首次更新仍需手动把 `Codex Switch.app` 拖入 `Applications`, 因为旧版本的更新逻辑不具备自动替换能力; 完成这次升级后, 后续更新即可自动替换并重启.
3. 自动替换的日志写入数据目录的 `update/apply-update.log`, 失败原因同时写入 `update/apply-update-result.txt`, 排错方式见[自动更新指南](https://github.com/azazo1/codex-switch/blob/main/docs/update-guide.md).
