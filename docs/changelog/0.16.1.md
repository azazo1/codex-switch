# Codex Switch v0.16.1

Date: 2026-09-10

本版本补上 Grok 和 OpenAI 中转计价脚本预设, 长 Base URL 在上游列表中改为截断显示, 并把托盘上当前上游余额统一成两位小数.

## Highlights

- 计价脚本编辑器新增 `Grok 中转价` 和 `OpenAI 中转价` 预设, 把官方美元标价当人民币再乘上游倍率.
- 上游列表的 Base URL 过长时保留开头并加省略号, 悬停仍显示完整地址.
- 托盘当前上游余额始终显示两位小数, 不再在大于等于 1 时改成一位小数.

## Upgrade Notes

1. 升级不涉及数据库迁移, 现有上游, 日志, 设置和计价脚本保持不变.
2. 需要按中转账单估算 Grok 或 OpenAI 费用时, 在计价脚本编辑器中选择对应预设, 并按 key 所在分组填写价格倍率.
3. 升级后可在仪表盘确认版本号, 并在上游列表和托盘余额处确认展示效果.

## Features

- 计价脚本: 新增 Grok 中转价预设. 中转把官方美元单价原样记成人民币, 再乘 `ctx.multiplier`; prompt >= 200k 时整单 2 倍.
- 计价脚本: 新增 OpenAI 中转价预设. 同样把官方美元单价当人民币再乘倍率; prompt > 272k 时输入侧 2 倍, 输出 1.5 倍.
- 界面: 上游列表改用可裁剪的表格列显示 Base URL, 空间不够时截断尾部并保留开头.

## Bug Fixes

- 托盘: 当前上游余额始终保留两位小数, 避免大于等于 1 时只显示一位小数.
