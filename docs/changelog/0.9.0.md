# Codex Switch v0.9.0

本版本加入普通模式持续调试日志, 扩展临时 Key 管理, 并修复多个 Chat Completions 兼容问题.

## Highlights

- 普通模式可在仪表盘开启完整调试日志, 不再依赖 debug 环境.
- 临时 Key 支持自定义值和编辑额度, 有效期等限制.
- Chat Completions 工具参数和 reasoning 转换兼容性提升.

## Features

- 仪表盘新增调试日志区域, 可立即开启 tracing 和完整代理 body 的持续写入.
- 日志按每日和单文件大小轮转, 可配置保留的轮转文件数, 并提供打开日志位置.
- 调试日志开关和轮转设置持久化到 SQLite, 下次启动继续生效.
- 临时 Key 支持自定义或自动生成, 编辑名称, key 值, 请求数, token 数和有效期.
- 临时 Key 有效期支持 `1d2h30m10s` 这类组合时长.
- 临时 Key 页面改为更紧凑的表格和可点击 K/M/B token 显示.

## Bug Fixes

- Chat Completions 工具缺少 `parameters` 或根类型时自动补齐, 修复 OpenCode Go 等严格上游拒绝 codex_app 工具的问题.
- Responses 上游统一把内部 reasoning marker 和 summary 还原为 `reasoning_text`.
- Chat Completions 转换会把 plaintext reasoning content 写入 `reasoning_content`.

## Upgrade Notes

- 调试日志默认关闭, 现有运行和日志行为不变.
- 首次启动会自动写入新增设置默认值, 不需要手动迁移.
