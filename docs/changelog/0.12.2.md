# Codex Switch v0.12.2

Date: 2026-08-28

本版本让已配对节点可以跟着发现结果更新地址, 并在多地址时优先使用同子网且能连上的那一个.

## Highlights

- 发现列表里已配对但 IP 或端口变了时, 可以点 `更新` 只改可达地址.
- 一个节点有多个地址时, 优先显示同子网并且 TCP 能连上的地址.
- 发现结果会去掉回环和链路本地地址, 避免把 `fe80` 这类地址当成可连入口.

## Features

- 节点: `更新` 会同步 `PeerNode` 上游 Base URL, 指纹对不上时不会改地址.

## Bug Fixes

- 节点: 更新发现地址后, 上游页会立刻显示新的 Base URL.

## Upgrade Notes

1. 从 0.12.1 升级无需额外数据库迁移.
2. 换局域网后打开发现, 对已配对且地址变化的节点点 `更新`, 再发一次模型请求确认转发走新地址.
