# Codex Switch v0.13.0

Date: 2026-09-09

本版本新增模型测试台, 可以在应用里直接向上游或调度组发测试请求并查看流式输出和费用. 同时带来 HAR 网络日志, 上游导入导出, 人民币汇率显示和按上游的价格倍率. 使用旧配置的用户请先阅读 Upgrade Notes 再升级.

## Highlights

- 新增 `模型测试` 页, 可直连上游或经调度组发测试请求, 支持流式输出, 思维链展示, 首 token 延迟和费用估算.
- 新增 HAR 网络日志, 把每个出站请求和响应写入 `codex-switch-network.har`, 可直接用 Chrome DevTools 打开.
- 上游支持 JSON 导入导出, 可单条或批量复制到剪贴板, 方便换机和备份.
- 费用展示支持 USD 和 CNY 切换, 汇率自动获取并缓存.
- 新增按上游的价格倍率, 用于校准中转站的实际计费.

## Upgrade Notes

1. 升级会执行 21 到 23 号数据库迁移, 只新增列并带默认值, 现有上游, 日志和设置保持不变.
2. 日志文件由一份拆成两份: `codex-switch.log` 记录应用运行日志, `codex-switch-proxy.log` 记录模型调用日志. 排查转发问题请查看后者.
3. 网络日志默认只在开启完整调试日志时写入, 会包含请求和响应正文, 请自行确认 `codex-switch-network.har` 的存放位置是否安全.
4. 需要自动刷新余额但不希望收到提醒时, 在余额设置里关闭提醒开关即可, 刷新和提醒现在是两个独立选项.
5. 升级后建议打开 `模型测试` 页, 对常用上游发一次测试请求确认链路正常.

## Features

- 模型测试: 支持单次测试和连续对话两种模式, 可直连上游或经调度组, 也可以临时指定上游和分组.
- 模型测试: 流式显示正文和思维链, 记录耗时, 首 token 延迟, tokens 与估算费用, 并可导出单条或全部记录为 HAR.
- 网络日志: 记录全部出站请求和响应, 采用流式追加结构, 进程随时退出后文件仍是合法 HAR.
- 网络日志: OAuth 相关请求和响应正文自动脱敏, `refresh_token`, `code` 和 `access_token` 不会明文落盘.
- 上游管理: 支持单条和批量 JSON 导出导入, 导出内容不含上游 id 和时间戳, 导入时重新生成.
- 上游管理: 依据 Base URL 自动识别上游类型, 预填 Wire API, 认证方式和余额 provider, 并支持一键补全不完整的地址.
- 模型列表: 按识别结果解析响应, 支持 `data` 与 `models` 数组, 顶层数组以及 `id`, `name`, `slug` 三种 ID 字段, 智谱 `/api/v1` 和 OpenCode 现在能正确列出模型.
- 费用统计: 支持 USD 与 CNY 切换, 点击费用数值即可切换币种, 汇率无缓存时回退 USD.
- 费用统计: 每个上游可设置价格倍率, 只影响费用估算, 不改变转发行为.
- 日志: 模型调用日志拆分为独立滚动文件, 与主日志共享轮转大小和文件数设置.
- 余额: 自动刷新与阈值提醒解耦, 可以只刷新不提醒.
- 临时 key: 新增重置用量按钮, 用尽的 key 可以立即复用, key 值, 限额和过期时间保持不变.
- 模型映射: 命中映射规则时, 响应里的模型名会还原成客户端请求的模型, 日志和活跃连接同时显示请求模型与目标模型.

## Bug Fixes

- 修复流式 HAR 导出只包含最后一段内容的问题, 现在保留完整响应.
- 修复测试台的思维链在输出结束后自动折叠, 以及滚动内层区域带动外层页面的问题.
- 修复智谱 `/api/v1` 上游模型列表为空的问题, 该端点鉴权失败也返回 HTTP 200, 现在会读取响应体里的错误码判断.
- 修复模型映射后日志只显示目标模型, 无法按客户端模型筛选的问题.
- 修复非 v1 的 API 前缀被改写, 以及 `/chat/completion` 一类别名路径无法命中的问题.
- 修复工具调用结果中内嵌的媒体仍进入文本模型的问题.
- 修复节点发现刷新后正在编辑的地址, 显示名和开关被覆盖的问题.
- 修复 macOS 托盘状态文字在窗口失焦时的显示问题.
