# Codex Switch v0.11.0

Date: 2026-08-06

本版本主要增强托盘和窗口体验: 托盘图标可以直接展示实时运行指标, 角标内容可以按需切换并跨启动保留, 主窗口的位置和大小也会在重启后自动恢复. Windows 托盘图标同时跟随系统深浅色主题, 多模态输入清洗后的提示文案更加明确.

## Highlights

- 托盘图标新增实时指标显示, 悬停可以查看服务状态, 活跃连接数, 总 TPS, 总字符速率, 今日请求数和缓存保持会话数.
- 托盘角标可在连接数, 总 TPS, 总字符速率, 今日请求数和缓存保持会话数之间切换, 也可以关闭, 选择会保存并在重启后恢复.
- 主窗口的位置和大小会在重启后自动恢复.
- Windows 托盘图标跟随系统深浅色主题切换.
- 被清洗的多模态输入会在描述中明确说明模型不支持对应输入.

## Features

- 托盘角标默认显示活跃连接数, 数值大于 99 时显示实际数值而不是 99+.
- Linux 桌面不支持托盘悬浮提示, 会在面板上显示当前所选指标的简短文字.
- 多模态输入清洗生成的占位描述会注明模型不支持图片, 音频或文件输入.
