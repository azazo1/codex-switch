# Codex Switch v0.7.0

本版本完善代理映射模型的返回与展示, 让 Codex 客户端在目标模型被重写后仍能看到正确的模型和工具调用.

## Mapped Responses

- JSON 与 SSE 的 mapped responses 会把响应模型重写回客户端模型, 避免把 target model 暴露给模型列表或详情 API.
- passthrough SSE 也会经过 bridge 重写, 不再直接转发可能包含 target model 的原始 chunk.
- 请求日志和活动连接会记录并显示请求模型与 target model, 支持按照实际模型过滤.
- UI 在请求模型和 target model 不同时会分两行展示, 相同则保持单行.

## Tool Mapping

- 修复 mapped function call 的 namespace 元数据丢失问题, 会重建 original tool name 和 namespace, 例如把 `mcp__node_repl__js` 恢复为 `js` 加 `mcp__node_repl`.
- 清理上游模型错误写入 arguments 的 namespace 字段, 保持 in-app browser 等工具可继续调用.

## Upgrade Notes

- 升级时会自动执行 schema migration 14, 不需要手动迁移数据.
