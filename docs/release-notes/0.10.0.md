# Codex Switch v0.10.0

Date: 2026-08-06

本版本为不支持多模态输入的模型增加请求清洗, 同时把模型价格和能力统一到一个本地信息缓存, 并修复若干代理兼容问题.

## Highlights

- 上游可开启 "为非多模态模型去除多模态输入", 自动把图片, 音频和文件替换为带媒体类型, 大小和文件名等信息的文字描述.
- 模型能力优先来自本会话 `/models` 接口, 未命中时使用 models.dev 落盘信息, 未知模型可配置按单模态或多模态处理.
- 仪表盘 "获取模型信息" 一次刷新模型价格和模态能力, 最近日志与活跃连接 hover 会显示模态能力.
- 修复 Chat Completions 中仅含推理内容的消息和日志文件被外部删除后的恢复问题.

## Features

- 上游编辑页新增多模态输入清洗开关, 覆盖 Responses, Chat Completions 和 Anthropic Messages, 包括 Anthropic tool_result 内媒体.
- 上游编辑页新增未知模态模型策略, 支持按单模态或多模态处理没有能力信息的模型.
- 模型价格和能力合并到 `model_info_cache`, 启动时会从已有价格原始 JSON 回填模态能力.
- 代理 `/models` 返回的能力字段会写入会话缓存, 模型列表实时缓存重启后失效.
- 最近请求和活跃连接 hover 增加模态能力显示.

## Bug Fixes

- 修复 reasoning-only assistant 消息在 Chat Completions 上游被拒绝的问题.
- 修复日志文件被外部删除后不会自动重建的问题.

## Upgrade Notes

1. 升级会依次执行 schema migration 17 到 19, 现有数据库会自动迁移.
2. 需要清洗多模态输入时, 请在每个上游编辑页中开启对应开关并选择未知模态策略.
3. 旧版本已有的 models.dev 价格数据会用于回填模态能力, 无需手动重新获取.
